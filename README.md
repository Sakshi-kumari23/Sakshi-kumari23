## 🥇 Augmented Reality Smart Maintenance Assistant

> **Computer Vision + Maintenance Knowledge + AR Guidance**

A major project focused on assisting machine maintenance through **computer vision and augmented guidance**.

### 🔄 Concept

```text
📷 Camera Input
       ↓
👁️ Computer Vision
       ↓
🔍 Part / Problem Detection
       ↓
📚 Maintenance Knowledge
       ↓
🧭 AR Guidance
       ↓
📱 Visual Instructions & Overlays
```

### 🔧 Core Technologies

**YOLO** • **OpenCV** • **Computer Vision** • **AR Guidance**

The project explores how a camera-based system can identify machine components or problems and present relevant maintenance guidance through visual overlays.
